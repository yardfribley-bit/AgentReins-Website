网站访问分析

为了了解发布流量并改进产品，我们记录时间、页面或下载架构、来源、IP 地址、User-Agent、设备、屏幕尺寸和语言。第一方匿名访客 ID 与会话 ID 用于区分重复访问和发布平台预览；我们也记录滚动深度、已查看的产品板块、30 秒有效停留、外部链接点击和下载意图。我们通过 IP 推测国家、地区、城市、ASN 和网络归属；这不是精确地址或个人身份。我们不收集表单输入、密码、广告标识符或跨网站浏览历史。

用途与保留时间

数据仅用于汇总发布分析、改进产品、防止滥用和运行安全。原始记录及 IP 位置结果最多保留 30 天，汇总计数可能保留更长时间。

AgentReins 应用

AgentReins macOS 应用采用本地优先设计。除非用户明确配置外部分析服务，Agent 证据保留在用户设备上。

你的选择

你可以通过浏览器隐私设置阻止统计请求，不影响网站访问。如需查询或删除数据，请发送邮件至 yardfribley@gmail.com 或提交 GitHub Issue。
